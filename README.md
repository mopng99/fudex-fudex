# fudex-fudex

مشروع فيودكس - https://fuerp.fudex.com.sa/

هذا الريبو **لا يحمل نواة FuERP**. يحمل ما يميّز هذا المشروع فقط،
ويبنيه فوق نواة `fuerp-fudex` عند النشر.

## البناء

```bash
./deploy.sh            # يبني إلى app_root
./deploy.sh --dry-run  # يعرض ما سيفعله دون كتابة
```

#### اتباع النواة

أي إصلاح في الكود الأساسي يُكتب في `mopng99/fuerp-fudex` ثم
يُدمج في `main`. هنا يُغيَّر `core_ref` في `project.yml`، ثم يُشغَّل
النشر. لا تُنسخ النواة إلى هذا الريبو.

التفاصيل في `docs/CUSTOM.md` داخل النواة.
